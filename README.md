# node-L (beta installer)

node-L is a physics-first structural modeling environment from **phi architecture φ** (Columbus, IN). It models joints and struts with real physics and solves the model on screen as a pin-jointed 3D truss.

**Research beta. Not for engineering decisions.** The Analysis tab checks member yield and Euler buckling only, and says so on screen.

## Download

Get `node-L-Setup-0.1.0-beta.1.exe` from the [latest release](../../releases/latest). Windows 10/11, x64. It installs per user (no administrator rights needed) and runs fully offline.

SHA-256: `aed2c64bc3ee2c4a12ce5e0eb6846f69a94ede89ffb87f68bbb139a9a1e02ae5`

## Windows SmartScreen warning

The installer is not code-signed yet, so Windows shows "Windows protected your PC". Click **More info**, then **Run anyway**.
